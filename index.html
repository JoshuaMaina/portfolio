Joshua Mwangi Maina builds systems where a wrong number costs money.

At Goldman Sachs that has meant pricing infrastructure. I built a clustered cache that made cross-asset pricing more than ten times faster1, a load balancer that lets us deploy to pricing systems mid-session with zero downtime2, and a new way to ship a core library that cut service start-up time by 90%3. Lately it means LLM agents: a platform where every user gets an isolated agent runtime4, and a trading chat that can’t make up a figure5.

Vice President and software engineer in London, working in Java and Python. I trained as an actuary, so I still think in failure modes and evidence. Each small number links to the page behind the claim. Scroll to read it from 2026 back to 2015, or jump to a year on the timeline.

Goldman Sachs, vice president

Multi-tenant agent platform

1 runtime per user

An internal platform where each user gets an isolated agent runtime, and traders can ship their own apps with no configuration. It works by convention: one parameterised Dockerfile, the folder name as the app’s identity, per-app CI builds and automatic service discovery. I implemented the A2A protocol on top of our MCP-based orchestration, and rebuilt the task lifecycle as an explicit state machine backed by Redis.

Python, MCP, A2A, Docker, GitHub Actions, Traefik, Redis
